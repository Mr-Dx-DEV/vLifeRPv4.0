
### INSTALL

1) Drag and drop `dz-torture` into your server resources
2) Ensure `dz-torture` in your server.cfg
3) Open `config.lua` file and config the script to your like
4) Add the `torture_kit` item bellow, to your items list in qbcore
5) Add the `torture_kit` image to your inventory items images folder
6) Restart your server


### TORTURE KIT ITEM
